# My GD List
1. Wejdź na https://github.com/ i załóż konto.
2. Utwórz nowe publiczne repozytorium, np. `my-gd-list`.
3. Wgraj `index.html`.
4. Wejdź w Settings → Pages.
5. Włącz publikowanie z gałęzi `main` i folderu `/ (root)`.
6. Po chwili GitHub poda adres Twojej strony.

Aby zmienić poziomy, edytuj tablicę `levels` w `index.html`.
